•	Objetivo del proyecto:
Sistema de generación e impresión de etiquetas personalizadas en hojas A4, a partir de los datos de un archivo Excel.
Optimizando la maquetación visual, el mapeo de campos, los precios y las guías de corte para refilado.
Permite diseñar el tamaño de las etiquetas, imagen de fondo e información que se elije mostrar en cada plantilla de etiquetas.
El sistema permite definir las medidas individuales de cada etiqueta, generando una plantilla para configurar una grilla por cada impresión en formato vertical A4
